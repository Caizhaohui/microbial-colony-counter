# 微生物菌落计数器

[![Python](https://img.shields.io/badge/Python-3.7+-blue.svg)](https://www.python.org/)
[![OpenCV](https://img.shields.io/badge/OpenCV-4.x-green.svg)](https://opencv.org/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

一个功能强大的微生物培养皿菌落自动计数工具，具有直观的图形界面和精确的图像处理算法。

## ✨ 功能特点

- 🖼️ **多格式支持**：支持 JPG、PNG、BMP、TIFF 等多种图片格式
- 🔍 **智能计数**：基于 OpenCV 的先进图像处理算法自动检测和计数菌落
- ⚙️ **参数调节**：提供丰富的参数调整选项，适应不同类型的培养皿
- 🎯 **区域选择**：支持手动选择统计区域（矩形/圆形），可拖拽调整
- 🧫 **培养皿检测**：自动检测培养皿圆形区域，排除背景干扰（已优化加速）
- 📊 **实时显示**：处理过程中实时显示原图、二值化和计数结果
- 💾 **结果保存**：可保存包含原始图片、二值化图片和计数结果的统计报告
- 🎨 **现代化界面**：顶部工具栏 + 最大化图片区域 + 底部结果栏的三层布局
- 🔧 **高级选项**：分水岭算法分离粘连菌落、圆度过滤等高级功能
- 📱 **Web App 支持**：支持通过手机浏览器远程访问，方便在实验室移动使用

## 🚀 快速开始

### 方法一：直接运行（需要 Python 环境）

1. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

2. **运行程序**
   ```bash
   python main.py
   ```

### 方法二：使用 Web App GUI 启动器

1. **运行启动器**
   - Windows: 双击 `run_gui.bat`
   - 或者运行: `python web_launcher.py`

2. **操作说明**
   - 点击界面上的 "启动服务" 按钮
   - 看到 "本机访问" 和 "手机访问" 地址
   - 手机和电脑在同一局域网时，手机扫描或输入地址即可使用

### 方法三：使用打包的可执行文件

1. **打包程序**
   ```bash
   python build.py
   ```

2. **运行可执行文件**
   - Windows: 双击 `dist/微生物菌落计数器.exe`
   - macOS/Linux: 运行 `dist/微生物菌落计数器`

### 方法四：优化打包（减小文件大小）

使用虚拟环境 + Nuitka + UPX 的优化方案：

```bash
python optimize_build.py
```

## 📖 使用指南

### 界面布局

新版 GUI 采用现代化的三层布局设计：

```
┌─────────────────────────────────────────────────────────────┐
│  工具栏：[📂打开] [✂️选区] [▶️处理] [💾保存]  参数设置...    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│    📷 原始图片    │    🔲 二值化    │    ✅ 计数结果          │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  📊 菌落总数: 154个  │  参数摘要  │  状态信息                │
└─────────────────────────────────────────────────────────────┘
```

### 基本操作流程

1. **打开图片**：点击 "📂 打开图片" 按钮，选择培养皿图片
2. **调整参数**：在顶部工具栏调整模糊、阈值、面积范围等参数
3. **选择区域**（可选）：点击 "✂️ 选择区域" 手动指定统计范围
4. **处理图片**：点击 "▶️ 处理" 开始分析
5. **查看结果**：中间区域显示原图、二值化和计数结果
6. **高级选项**（可选）：点击 "⚙️ 高级选项" 启用分水岭、圆度过滤等
7. **保存结果**：点击 "💾 保存" 保存统计报告

### 参数说明

#### 常用参数（顶部工具栏）
- **模糊**：高斯模糊核大小，建议 3-15 之间的奇数
- **阈值**：
  - 自适应阈值：自动适应图片亮度（推荐）
  - 手动阈值：手动设置阈值值
- **面积**：菌落面积范围 [最小值, 最大值]，过滤噪点和非菌落物体

#### 高级选项（点击 ⚙️ 高级选项）
- **分水岭算法**：分离粘连菌落（⚠️ 可能导致过分割）
- **圆度过滤**：按圆度筛选菌落（0=不过滤，90=只保留圆形）
- **边缘距离**：排除靠近边缘的菌落

#### 培养皿检测
- 勾选 "培养皿检测" 复选框可自动识别培养皿区域，只统计皿内菌落

### 手动选择区域

1. 点击 "✂️ 选择区域" 按钮
2. 选择形状（圆形/矩形）
3. 在图片上拖拽选择区域，可拖拽调整位置
4. 确认选择后关闭选区窗口，再进行处理
